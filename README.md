# Métro 2033 — Aventures I

Module d'aventure Foundry VTT (v14) pour le système [Métro 2033 — Year Zero Engine](https://github.com/vinceblaz/Metro-2033---YZE) (≥ 0.9.7) : le didacticiel et les scénarios 1 à 3 du livre de base en journaux.

Mise en route : initialiser le système (macro du système), puis lancer la macro « Métro 2033 — Importer l'aventure I ». Voir la page « Bienvenue » du journal importé. La macro crée aussi les PNJ génériques (garde, stalker, criminel, travailleur, personnel administratif) dans le compendium « Métro 2033 — PNJ Aventures I » et dans l’onglet Acteurs.

Scènes : 11 cartes de Petchatniki (`scenes/`), importées par la même macro dans le compendium « Métro 2033 — Scènes Aventures I » et l’onglet Scènes.

Contenu : `content/*.md` (mini-langage décrit dans `src/adventure/markup.mjs`). Tests : `node --test $(find tests -name '*.test.mjs')`.

Œuvre de fan non officielle. Texte du livre d'Arkhane Asylum : usage privé uniquement, ne pas redistribuer sans accord des titulaires des droits.
